# 可复现性

正式配置是实验参数来源；运行开始保存最终生效的完整配置快照。重要超参数不要散落于代码；未知字段不可静默忽略。简单 YAML/JSON 足够时不引入复杂配置系统。

按契约控制 Python、NumPy 和 PyTorch 随机种子，必要时控制 DataLoader worker 与 generator；记录 CUDA 与确定性算法设置。说明确定性与性能的取舍，不承诺跨硬件、驱动或依赖版本逐位相同。

数据清单记录真实来源与版本、获取日期、许可/引用、必要校验、预处理参数、划分方法和种子、生成程序及代码版本。特征缓存标注数据、预处理、模型权重版本；版本不匹配时拒绝混用。

根据恢复需求保存模型、优化器、调度器、epoch/step，以及确实影响恢复的 AMP 或随机状态。区分最佳评估 checkpoint、继续训练 checkpoint 和仅用于推理的权重；Lightning 优先使用框架原生 checkpoint。

多随机种子结果只根据实际运行记录汇总。比较实验若使用不同划分、指标定义、候选集或训练预算，要说明公平性限制。run_id、配置、数据版本、代码/依赖版本、指标与结果文件应能够相互追踪。
